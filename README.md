# Assembly Char Counter

Our objective is to develop a program that enables to input a text and show the amount of characters and its classification, using Assembly language (MASM) for the backend with an x86 architecture and a clear presentation in the C++ interface.

## Project Structure

- `src/frontend-cpp`: User interface and control logic in C++.
- `src/backend-asm`: Low level functionalities in Assembly.
- `resources/`: Assets, configurations and images.
